Small free tools that run offline. No accounts, no servers, no telemetry.
Nothing leaves your machine. Most of these started as something I needed and
turned out to be useful to other people.

---

**[Carryover](https://github.com/cig13zs/carryover)** · Chrome extension · [live demo](https://cig13zs.github.io/carryover/)

See how full your ChatGPT, DeepSeek or Grok conversation is getting, then pack
the key decisions and code into a handoff doc for a fresh chat. No permissions
and no network requests, so it can't leak your conversations. The summary is
pattern-matched out of the text rather than generated, so it can't invent
decisions you never made.

---

**[Invisibles](https://github.com/cig13zs/invisibles)** · Web app and Chrome extension · [live site](https://cig13zs.github.io/invisibles/)

Reveal and strip hidden Unicode characters from text: zero-width spaces,
look-alike spaces, bidi controls (Trojan Source), watermark characters. Runs
entirely in the browser. Also ships as a popup extension with no permissions.

---

**[Rinse](https://github.com/cig13zs/rinse)** · Browser tool · [live site](https://cig13zs.github.io/rinse/)

Reveal the GPS, camera model and timestamp buried in a photo's EXIF data, then
wash it off with a canvas re-encode. Every "remove EXIF online" tool uploads
your photo to a server first. This one never opens a connection.

---

**[Return Google Cache](https://github.com/cig13zs/return-google-cache)** · Chrome extension · [live site](https://cig13zs.github.io/return-google-cache/)

Google killed the Cached link in 2024. This puts it back on every result, using
the Wayback Machine and archive.today. MV3, no permissions, Google Search only.

---

**[Return 100 Results](https://github.com/cig13zs/return-100-results)** · Chrome extension · [live site](https://cig13zs.github.io/return-100-results/)

Google disabled `&num=100` in 2025. Loads the next pages inline as one long list
of about 100 results. One click per page so it stays under the radar. MV3, no
permissions.
