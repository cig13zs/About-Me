---

**[Carryover](https://github.com/cig13zs/carryover)** · Chrome extension — [live demo](https://cig13zs.github.io/carryover/)

See how full your ChatGPT, DeepSeek, or Grok conversation is getting, then pack
the key decisions and code into a handoff doc for a fresh chat. Zero permissions,
zero network requests — it can't leak your conversations. Pattern-matched
summaries, not LLM-generated, so it can't invent decisions you never made.

---

**[Invisibles](https://github.com/cig13zs/invisibles)** · Web app + Chrome extension — [live site](https://cig13zs.github.io/invisibles/)

Reveal and strip hidden Unicode characters from text — zero-width spaces,
look-alike spaces, bidi control chars (Trojan Source), AI watermark chars. 100%
client-side, nothing uploaded. Also ships as a zero-permission popup extension.

---

**[Rinse](https://github.com/cig13zs/rinse)** · Browser tool — [live site](https://cig13zs.github.io/rinse/)

Reveal the hidden GPS, camera model, and timestamp buried in a photo's EXIF data
— then wash it off via canvas re-encode. Every "remove EXIF online" tool uploads
your photo to a server; Rinse never opens a connection.

---

**[Return Google Cache](https://github.com/cig13zs/return-google-cache)** · Chrome extension — [live site](https://cig13zs.github.io/return-google-cache/)

Google killed the Cached link in 2024. This puts it back on every result —
Wayback Machine + archive.today. MV3, no permissions, Google Search only.

---

**[Return 100 Results](https://github.com/cig13zs/return-100-results)** · Chrome extension — [live site](https://cig13zs.github.io/return-100-results/)

Google disabled `&num=100` in 2025. Load the next pages inline as one long list
(~100 results). One click per page to stay under the radar. MV3, no permissions.
